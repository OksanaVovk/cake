# 🍰 Original Desserts

**Original Desserts** is a frontend web application that allows users to order
desserts and pizza with **home delivery** or **self pickup** options.

The project focuses on building a smooth and intuitive ordering experience using
modern frontend technologies.

---

## 🚀 Project Overview

The application enables users to:

- Browse desserts and pizza
- Add products to the cart
- Remove products from the cart
- Place an order with delivery or pickup options

All cart and order logic is handled on the client side.

---

## 🖥️ Frontend

- **React** – component-based architecture
- **Redux** – state management for cart and orders
- **Styled Components** – component-level styling

Key UI features:

- Clean and responsive design
- Dynamic cart updates
- Real-time product quantity management

---

## 🛒 Cart & Order Logic

Redux is used to manage:

- Adding products to the cart
- Removing products from the cart
- Storing the current order state

This approach ensures predictable state management and a scalable architecture.

---

## 🛠️ Tech Stack

- React
- Redux
- Styled Components

---

## 🌱 Purpose

This project was created as a **frontend-focused application** to practice:

- State management with Redux
- Component-based UI design
- Cart and order logic implementation
- Building a real-world e-commerce-like flow
